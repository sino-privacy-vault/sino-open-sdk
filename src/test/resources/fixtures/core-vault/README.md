# Core interop fixture

A small vault written by Sino's own core code (not by this SDK), so the SDK tests prove it reads what the apps
write. Generated by `SdkFixtureGenerator` in the Sino repository (`sino-core/src/jvmTest`); regenerate it there
whenever a cloud format changes. The keys are random test keys; `phrase.txt` is a test phrase.

- `provider-a/SinoVault`, `provider-b/SinoVault`: two providers' copies, as downloaded from the cloud.
- Contents: the recovery backup, a signed device list (two devices, one revoked), a folder only provider B has the
  newest batch of, a tombstone that wins over a lagging batch, a trashed file, a decoy vault namespace, a two-chunk
  file, gzip-compressed files and Unicode folder and file names.
- `expected.json`: the SHA-256 of every file a recovery must produce.
